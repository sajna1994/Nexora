# NEXORA — MERN E-commerce Starter

Premium multi-category e-commerce foundation for Shoes, Gym/Supplements, and future Fashion/Cosmetics/Accessories.

## Stack
- React + Vite + TypeScript
- Ant Design
- React Router
- Node.js + Express + TypeScript
- MongoDB + Mongoose
- JWT-ready auth structure

## Run
### Client
cd client
npm install
npm run dev

### Server
cd server
npm install
npm run dev

Create `server/.env` from `.env.example`.
